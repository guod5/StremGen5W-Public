# Stremio Auto launcher artwork

The Android launcher icon is the user-selected IONIQ-style pixel play design, stored at `app/src/main/res/drawable-nodpi/stremio_auto_icon.webp`. It uses the Stremio-inspired purple-to-blue diamond design with the white play symbol rendered as square pixels. The icon was adapted from a user-selected image; the app is an unofficial community project.

The original, unmodified Stremio SVG is retained at `branding/stremio-logo-icon-only-fullcolor.svg` for reference and attribution but is **not used by the Android build**.

Original icon source: https://github.com/Stremio/stremio-brand/blob/master/logos/SVG/stremio-logo-icon-only-fullcolor.svg
